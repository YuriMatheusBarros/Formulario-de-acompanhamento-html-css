Formulário de Contato HTML
Este é um formulário de contato simples desenvolvido em HTML com estilos CSS inline.

Estrutura do Projeto
O formulário contém os seguintes campos:

Informações básicas

Nome (obrigatório)

Sexo (opções: Feminino, Masculino, Outro)

Email (obrigatório)

Telefone (obrigatório)

Detalhes da mensagem

Assunto (obrigatório)

Gravidade da solicitação (escala de 0 a 10)

Data de envio

Anexo de arquivo

Área de mensagem

Campo de texto para a mensagem principal (obrigatório)

Botões de ação

Enviar (submit)

Resetar (limpar formulário)

Estilização
O formulário utiliza CSS interno com as seguintes classes:

.botao - Estilo para o botão de envio

.botao2 - Estilo para o botão de reset

.mensagem - Estilo para a área de texto da mensagem

.formulario - Estilo para a imagem do cabeçalho

Como Utilizar
Basta abrir o arquivo HTML em qualquer navegador moderno

Preencher os campos obrigatórios (marcados com *)

Clicar no botão "Enviar" para submeter o formulário
